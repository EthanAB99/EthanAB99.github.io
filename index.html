Part one / Distance to a function

A geometric problem, an optimization solution.

Find the shortest distance from (0, 0), (−4, 0), (−8, 0), (2, 0), and (6, 0) to y = x² + 5. Compare the analytical solution with both supplied numerical routines.

D(x) = (x − x₀)² + (f(x) − y₀)²Minimize squared distance; take √D only when reporting the Euclidean distance.

Start with the derivative

A stationary point satisfies D′(x) = 2(x − x₀) + 2(f(x) − y₀)f′(x) = 0. For f(x) = x² + 5 and y₀ = 0:

2x³ + 11x − x₀ = 0

Since D″(x) = 12x² + 22 > 0, D is strictly convex. Its single stationary point is the global minimum. The connecting segment is perpendicular to the curve’s tangent.

Solve the cubic analytically

Dividing by two gives x³ + (11/2)x − x₀/2 = 0. Cardano’s real-root formula gives:

x* = ∛(x₀/4 + √Δ) + ∛(x₀/4 − √Δ)
Δ = x₀²/16 + (11/6)³Use real cube roots. Then d = √((x* − x₀)² + (x*² + 5)²).

Worked example: the point (2, 0)

Here Δ = 0.25 + (11/6)³ = 6.412037037. Substitution gives x* = 0.180744604, so the closest point is (0.180744604, 5.032668612), and d = √(3.309690194 + 25.327753359) = 5.351396411. For (0, 0), symmetry gives x* = 0 and d = 5 exactly.

How the methods reach the answer

Uses derivatives

Newton–Raphson

Apply Newton to D′(x), using D″(x) as its derivative:

xₖ₊₁ = xₖ − D′(xₖ) / D″(xₖ)For this parabola: xₖ₊₁ = xₖ − (2xₖ³ + 11xₖ − x₀)/(6xₖ² + 11).

For (2, 0), start at x₀ = 0: x₁ = 0 − (−2)/11 = 0.181818182. The next iterate is 0.180744717. The third is already within 10⁻¹⁴ of the root.

The subscript on xₖ denotes an iterate; x₀ in the objective denotes the input point’s coordinate.

Derivative free

Golden-section search

With r = (3 − √5)/2 ≈ 0.381966, evaluate x₁ = a + r(b − a) and x₂ = b − r(b − a). If D(x₁) < D(x₂), retain [a, x₂]; otherwise retain [x₁, b].

For (2, 0) on [0, 2], x₁ = 0.763932 and x₂ = 1.236068. Their squared distances are 32.704365 and 43.196601, so the first retained interval is [0, 1.236068].

The file is named Bisection.py, but its implementation is golden-section minimization, not root bisection.

Choose the domain before the algorithm

For ln x, all evaluations must stay at x > 0. For 1/x, search the negative and positive branches separately and compare their minima. A single interval crossing zero is invalid. For √x, test the endpoint x = 0 as well as interior candidates; its derivatives are singular at zero.

Convergence needs a check

Newton can leave the domain, divide by near-zero curvature, or find an unsuitable stationary point. Golden-section search needs a unimodal objective on its interval. In the examples above, compare both reciprocal branches; for √x, the endpoint distance is 2, exceeding the interior result √1.75.

For (2, 0), the exponential objective is strictly convex. The logarithmic objective has positive second derivative on x > 0; the reciprocal objective is strictly convex on each branch; and the radical objective simplifies to (x − 2)² + x. These properties support the reported minima. The bounded intervals contain the relevant stationary points.

Part two / Fitting to an equation

One dataset. Two models.

Fit a line and a quadratic to (0, 0.5), (2, 3.5), (1, 1.5), and (3, 7.5) by minimizing mean squared vertical error.

MSE(θ) = ¼ Σᵢ₌₁⁴ (ŷᵢ − yᵢ)²Line: ŷ = c + bx. Quadratic: ŷ = c + bx + ax². Unlike Part One, these residuals are vertical, not perpendicular distances.

Line · analytical solution

Σx = 6, Σx² = 14, Σy = 13, and Σxy = 31. Setting the two partial derivatives to zero gives:

4c + 6b = 13
6c + 14b = 31

Subtract 1.5 times the first equation from the second: 5b = 11.5. Thus b = 2.3 and c = (13 − 6b)/4 = −0.2.

In ascending x order, residuals are −0.7, 0.6, 0.9, −0.8. MSE = (0.49 + 0.36 + 0.81 + 0.64)/4 = 0.575.

Quadratic · analytical solution

Also Σx³ = 36, Σx⁴ = 98, and Σx²y = 83. The three normal equations are:

4c + 6b + 14a = 13
6c + 14b + 36a = 31
14c + 36b + 98a = 83

Eliminating c yields 5b + 15a = 11.5 and 15b + 49a = 37.5. Their difference gives 4a = 3, hence a = 0.75, b = 0.05, c = 0.55.

Residuals in ascending x order are 0.05, −0.15, 0.15, −0.05. MSE = 0.05/4 = 0.0125.

Sequential Newton updates

Optimize one coefficient at a time while holding the others fixed, then use that newest value for the next coefficient. For a design column φⱼ, ∂MSE/∂θⱼ = (2/4)Σφᵢⱼ(ŷᵢ − yᵢ) and ∂²MSE/∂θⱼ² = (2/4)Σφᵢⱼ². A scalar Newton step exactly minimizes that coordinate’s quadratic objective.

c ← (13 − 6b)/4
b ← (31 − 6c)/14Line: repeatedly update c, then b.
c ← (13 − 6b − 14a)/4
b ← (31 − 6c − 36a)/14
a ← (83 − 14c − 36b)/98Quadratic: repeatedly update c, then b, then a.

Starting with all coefficients at zero gives MSE = 17.75. The first c update gives c = 3.25 and MSE = 7.1875. Next, b = (31 − 6 × 3.25)/14 = 0.821428571 and MSE = 4.825892857. For the quadratic, the next update gives a = (83 − 14 × 3.25 − 36 × 0.821428571)/98 = 0.080903790 and MSE = 4.665529988.

This is coordinate-wise Newton (equivalently, Gauss–Seidel on the normal equations), as requested by the one-parameter-at-a-time procedure. Full multivariate Newton uses the entire Hessian and would solve this unconstrained quadratic objective in one step in exact arithmetic.

03

Discussion / What the results tell us

The answer is only half the story.

Agreement is a useful check

On the strictly convex parabola problem, the analytical, golden-section, and Newton distances agree. Newton converges rapidly with valid derivatives; golden-section trades derivative information for steady interval reduction. Neither method should be judged solely by a plot that appears smooth.

Better fit, slower coordinate convergence

The quadratic lowers training MSE by about 97.83% (0.575 → 0.0125). Its extra parameter captures the curvature in these four points. The correlated columns 1, x, and x² also make sequential coefficient updates converge more slowly: 1,521 updates versus 90 in the supplied exports.

Bounds and starting points matter

The original experiments show issues near log and reciprocal domain boundaries and near the radical endpoint. Choose continuous intervals, check boundaries, and inspect the objective. Being farther from a curve does not by itself imply that a smaller numerical tolerance is needed.

Keep the claims within the evidence

A lower error on four training points does not establish better predictions on new data. The fitting comparison measures vertical residuals, while the distance experiment measures Euclidean distance. These are distinct objectives and should not be compared as the same error metric.

Complete reproducible Python: distance methods and curve fitting

Requires Python and NumPy. Saves new CSVs with the prefix “reproduced_” so the original data stays intact. Uses a maximum coefficient change of 10⁻⁸ over a complete sweep as its fitting stop criterion; update counts may differ from the original exports.

"""SYDE 572: reproducible distance and sequential Newton fitting examples.
Requires numpy. Run: python assignment1_reproduce.py
The two original distance routines remain available separately on the webpage.
"""
import math
import csv
import numpy as np


def golden(x0, y0, f, a, b, tol=1e-7):
    # Use a continuous, unimodal objective on [a, b].
    ratio = (3 - math.sqrt(5)) / 2
    D = lambda x: (x-x0)**2 + (f(x)-y0)**2
    left, right = a + ratio*(b-a), b - ratio*(b-a)
    fl, fr = D(left), D(right)
    history = []
    while b-a > tol:
        history.append((a, b, left, right, fl, fr))
        if fl < fr:
            b, right, fr = right, left, fl
            left = a + ratio*(b-a)
            fl = D(left)
        else:
            a, left, fl = left, right, fr
            right = b - ratio*(b-a)
            fr = D(right)
    x = (a+b)/2
    return x, math.sqrt(D(x)), history


def newton(x0, y0, f, df, ddf, start=0., tol=1e-7):
    x, history = start, []
    for k in range(100):
        g = 2*(x-x0) + 2*(f(x)-y0)*df(x)
        H = 2 + 2*df(x)**2 + 2*(f(x)-y0)*ddf(x)
        history.append((k, x, math.hypot(x-x0, f(x)-y0)))
        if abs(H) < 1e-14:
            raise ValueError("Near-zero curvature: change the starting point.")
        nxt = x-g/H
        if not math.isfinite(nxt):
            raise ValueError("Non-finite Newton step.")
        if abs(nxt-x) < tol:
            x = nxt
            if abs(2*(x-x0)+2*(f(x)-y0)*df(x)) > 1e-6:
                raise ValueError("Small step without a stationary point.")
            return x, math.hypot(x-x0, f(x)-y0), history
        x = nxt
    raise RuntimeError("Newton did not converge; check domain and initial guess.")


def fit(degree, filename, tol=1e-8):
    x = np.array([0., 2., 1., 3.])
    y = np.array([.5, 3.5, 1.5, 7.5])
    A = np.column_stack([x**j for j in range(degree+1)])
    theta = np.zeros(degree+1)  # c, b, then a
    labels = ['c', 'b', 'a'][:degree+1]
    mse = lambda: float(np.mean((A@theta-y)**2))
    rows = [[0, 'initial', *theta, mse()]]
    for cycle in range(100000):
        old = theta.copy()
        for j in range(degree+1):
            residual = A@theta-y
            gradient = 2*np.mean(A[:, j]*residual)
            curvature = 2*np.mean(A[:, j]**2)
            theta[j] -= gradient/curvature
            rows.append([len(rows), labels[j], *theta, mse()])
        if max(abs(theta-old)) < tol:
            break
    else:
        raise RuntimeError('Coordinate Newton did not converge.')
    exact = np.linalg.solve(A.T@A, A.T@y)
    assert np.allclose(theta, exact, atol=1e-6)
    with open(filename, 'w', newline='') as out:
        writer = csv.writer(out)
        writer.writerow(['update', 'variable_updated', *labels, 'MSE'])
        writer.writerows(rows)
    print('degree', degree, 'analytical', exact, 'numerical', theta,
          'MSE', mse(), 'individual updates', len(rows)-1)


if __name__ == '__main__':
    for p in [0, -4, -8, 2, 6]:
        u = np.cbrt(p/4 + np.sqrt(p*p/16 + (11/6)**3))
        v = np.cbrt(p/4 - np.sqrt(p*p/16 + (11/6)**3))
        exact = float(u+v)
        g = golden(p, 0, lambda x: x*x+5, -10, 10)
        n = newton(p, 0, lambda x: x*x+5, lambda x: 2*x, lambda x: 2.)
        print('point', (p, 0), 'exact x', exact, 'golden', g[:2], 'Newton', n[:2])
        assert abs(g[1]-n[1]) < 1e-9
    examples = [
        ('exp', math.exp, math.exp, math.exp, -5, 2, 0),
        ('log', math.log, lambda x: 1/x, lambda x: -1/x**2, .01, 5, 1),
        ('reciprocal', lambda x: 1/x, lambda x: -1/x**2,
         lambda x: 2/x**3, .01, 5, 2),
        ('sqrt', math.sqrt, lambda x: .5/math.sqrt(x),
         lambda x: -.25/x**1.5, .00001, 5, 1),
    ]
    for name, f, df, ddf, lo, hi, start in examples:
        g = golden(2, 0, f, lo, hi)
        n = newton(2, 0, f, df, ddf, start)
        # Compare disconnected reciprocal branches and the radical endpoint.
        candidates = [g[:2]]
        if name == 'reciprocal':
            candidates.append(golden(2, 0, f, -5, -.01)[:2])
        if name == 'sqrt':
            candidates.append((0., 2.))
        best = min(candidates, key=lambda item: item[1])
        print(name, 'point (2,0)', 'best', best, 'Newton', n[:2])
        assert abs(best[1]-n[1]) < 1e-8
    fit(1, 'reproduced_line_iterations.csv')
    fit(2, 'reproduced_quadratic_iterations.csv')
